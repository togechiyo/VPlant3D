# VPlant3D Booth初月5万円 売上計画

作成日: 2026-06-11

## 目的

ハッカソン提出後の次の目標として、VPlant3DをBoothで初月売上5万円を狙えるアプリに育てる。

前提:

- 通常版は無料配布
- 同内容の開発支援版を500円で販売
- 有料版だけに機能差をつけない
- 支援版は「今後の開発を応援したい人向け」
- 主な対象は、OBSでVRMアバターを気軽に使いたい個人配信者、VRMユーザー、開発者寄りの配信者

## 売上目標の分解

初月5万円の売上には、500円の開発支援版が100本必要。

ただし、手数料差し引き後の入金額で5万円を見たい場合は、100本では足りない可能性が高い。BOOTHの手数料は変更され得るため、販売開始前に公式ヘルプで再確認する。

目安:

- 売上5万円: 500円 x 100本
- 入金5万円狙い: 500円 x 110-120本程度を仮目標にする
- 無料DLから支援版購入への転換率が5%なら、無料DL 2,000件で支援100件
- 転換率が10%なら、無料DL 1,000件で支援100件

このため、初月の実務目標は「100人に売る」ではなく「1,000-2,000人に無料版を見てもらい、100人に支援したいと思ってもらう」に置く。

## 商品コンセプト

### 一言

OBSにVRMをそのまま載せる、軽量アバターレイヤー。

### もう少し詳しく

VPlant3Dは、OBS Browser SourceにVRMアバターを表示するための軽量アプリ。配信、録画、音声ミキシング、シーン制御はOBSに任せ、VPlant3Dはアバター表示、口パク、表情、簡易操作に集中する。

### Booth向けの訴求

- OBSでVRMを表示したい
- カメラなしでもVTuber風に動かしたい
- 既存の大きなVTuberソフトほど多機能でなくてよい
- 透明背景でOBSに合成したい
- 無料で試して、気に入ったら開発支援したい

## 差別化ポイント

### 1. OBSワークフローを尊重する

VPlant3DはOBSを置き換えない。OBSに貼るVRMレイヤーとして振る舞う。

ユーザーにとっての利点:

- OBSのシーン、音声、録画、配信設定をそのまま使える
- アバターだけをBrowser Sourceとして追加できる
- 既存の配信レイアウトに組み込みやすい

### 2. カメラなしでも使える

カメラトラッキングは便利だが、顔出しリスク、環境差、認識品質の問題がある。VPlant3Dはマイク口パク、表情ボタン、マウス手動操作、自動まばたきで「カメラなしの最低限VTuber感」を作れることを強みにする。

### 3. 軽量・小さい・portable

Windows portable版を中心にする。インストール不要で、zipを展開して起動できる。

「ちょっと試す」までの心理的ハードルを下げる。

### 4. VRMA対応を見せ場にする

VRMAはまだ一般層に普及しているとは言いづらいが、VRMアワード / MadeWithVRM文脈ではアピールしやすい。

大きな主機能ではなく、「短いモーションを再生できる」デモ要素として扱う。

### 5. 開発過程が見える

Codex主導で短期開発し、試行錯誤をdocsへ残している。一般ユーザー向けには前面に出しすぎないが、開発者・VRM技術好きには刺さる要素。

## 初月に必要な機能改善

売上を作るために必要なのは、新機能の多さより「初回起動で迷わない」「OBSに出る」「見た目が崩れない」こと。

### Priority A: 商品としての安心感

- Windows portable zipをわかりやすい名前にする
- 起動後に最初にやることを画面内に表示する
- OBS URLコピーをさらに目立たせる
- サンプルスクリーンショットを用意する
- 既知の制限をREADMEとBoothに明記する
- エラー時に「何をすればよいか」を表示する

### Priority B: 使ってすぐ楽しい体験

- VRM読み込み後、初期表示を見栄えよくする
- 表情プリセットを押したときに気持ちよく変わる
- マイク口パクがわかりやすく動く
- マウス手動操作の説明を短く表示する
- 位置調整のプリセットを追加する
  - バストアップ
  - 全身
  - 右寄せ
  - 左寄せ

### Priority C: 見た目の差別化

- ライトプリセットを少数に絞る
  - 標準
  - 明るめ
  - ライブ風
- 背景透過時の見え方を安定させる
- リムライトやエッジ表現は、チラつかない範囲で追加検討

### Priority D: 不安定機能を隠す

- ハンドトラッキングは通常導線から外す
- カメラモードは「簡易」と明記する
- 高度なモーキャプを売りにしない
- 壊れやすい機能は実験欄へ隔離する

# VPlant3D for OBS

VPlant3D for OBSは、VRMアバターをOBS Browser Sourceに表示するための軽量アプリです。

## リスク

### 1. 無料DLは伸びても支援されない

対策:

- 支援版の目的を明確にする
- 開発予定を具体的に書く
- 支援が改善につながることを見せる

### 2. OBS設定でつまずく

対策:

- 使い方画像を作る
- OBS URLコピーを目立たせる
- トラブルシュートをBoothにも書く

### 3. 既存VTuberツールと比べられる

対策:

- 高機能VTuberツールとして売らない
- 「OBSに軽く載せる」「カメラなしでも使える」「Browser Source向け」に絞って訴求する

### 4. Mac版の配布が難しい

対策:

- 初期はWindows portableを正にする
- macOSは開発者向け扱いにする
- 支援が集まったら署名 / notarizationを検討する
