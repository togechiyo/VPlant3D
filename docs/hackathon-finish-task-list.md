# Hackathon Finish Task List

最終更新日: 2026-05-29

## 目的

2026-06-07 の VRMアワード / `#MadeWithVRM` ハッカソン締切に向けて、VPlant3Dを「動く実験」から「見せられるアプリ」へ畳むためのタスクリスト。

ここからは新しい大機能より、デモ安定性、操作の分かりやすさ、見た目の説得力、READMEと提出導線を優先する。

## 方針

- 高精度モーキャプを主役にしない
- ハンドトラッキングは実験機能へ下げる
- OBS Browser Sourceで軽く動くVRMレイヤーとして仕立てる
- カメラなしでも使える、マイク口パク、表情、VRMA、手動操作、照明・見た目調整を強みにする
- 2026-06-04 以降は新しい大機能を原則追加しない
