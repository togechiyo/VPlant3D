# VPlant3D 現在の課題100

作成日: 2026-06-11

## 目的

ハッカソン提出後、Boothで初月5万円を狙えるアプリへ育てるため、現時点の課題を広めに洗い出す。

このリストは「全部やる」ためのものではなく、優先度づけ、Issue化、ロードマップ整理の材料として使う。

## 次の整理方針

この100項目を、そのまま全部Issue化すると散らかる。まずはBooth公開に効くものだけを `v0.2 Booth Readiness` としてまとめる。

候補:

- 初回起動ガイド
- OBS URLコピー導線改善
- 画角プリセット
- マイク口パク感度調整
- FAQ / トラブルシュート
- Booth商品画像 / スクショ構成
- Windows portable配布説明

ハンドトラッキング、本格モーキャプ、複雑な見た目編集、macOS署名は重要だが、初月売上への即効性が低いか、作業量が大きいため後回しにする。
