# VPlant3D for OBS How to Use

確認日: 2026-06-06

## これは何？

VPlant3D for OBSは、VRMアバターをOBS Browser Sourceに表示するためのアプリです。

画面は大きく2つに分かれます。

- Controller: VRM読み込み、マイク、カメラ、表情、位置調整を操作する画面
- OBS Render: OBS Browser Sourceに貼る表示専用画面

OBS Render側には操作UIを出さず、アバターだけを映す前提です。

## 事前に用意するもの

- Node.js / npm
- OBS
- 表示したいVRMファイル
- 必要ならVRMAファイル
- マイク口パクを使う場合はマイク
- カメラモードを使う場合はカメラ
- Tauri版を使う場合はRust / Cargo

## Web版で起動する

リポジトリのルートで実行します。

```bash
npm install
npm run dev
```

Controllerを開きます。

```text
http://127.0.0.1:5173/?control=1
```

ブラウザはChrome系を推奨します。OBS Browser SourceもChromium系なので、挙動確認が近くなります。

## Tauri版で起動する

```bash
npm run tauri:dev
```

Rust / Cargoが見つからない場合は、PATHを通してから起動します。

```bash
export PATH="$HOME/.cargo/bin:$PATH"
npm run tauri:dev
```

Tauri版は起動時にRust製Local Relayを立て、Controller画面を開きます。`5173` が使用中の場合は、近い空きportを使います。

OBSに貼るURLはController画面に表示されるものを使ってください。

## VRMを読み込む

1. Controllerの `VRMを読み込む` を押す
2. ローカルの `.vrm` ファイルを選ぶ
3. 上部プレビューにモデルが表示されることを確認する
4. OBS側にも同じモデルが表示されることを確認する

VRMファイルはローカルで読み込まれ、一時的にLocal Relay経由でOBS Renderへ渡されます。リポジトリには保存されません。

## OBSに表示する

1. OBSで `ソース` の `+` を押す
2. `ブラウザ` を追加する
3. URL欄へControllerに表示されたRender URLを貼る
4. 幅を `1920`、高さを `1080` にする
5. 背景を透過したい場合は `transparent=1` 付きURLを使う

URL例:

```text
http://127.0.0.1:5173/?obs=1&transparent=1
```

Tauri版やport衝突時はport番号が変わることがあります。必ずControllerに表示されているURLを優先してください。

## 操作モード

Controllerには主に2つの操作モードがあります。

### マイク&手動

カメラを使わずにVTuber風の動きを作るモードです。

できること:

- マイク音量で口を動かす
- 自動まばたき
- 表情プリセット
- マウス操作で顔向きやモデル位置を調整
- VRMA再生

カメラを使いたくない配信者向けの基本モードです。

### カメラ

カメラ入力から顔や上半身の動きを取るモードです。

できること:

- 顔の向き
- まばたき
- 口の開閉
- 体幹の簡易追従

注意:

- カメラ画像は表示せず、骨格やデバッグ表示だけを使います
- ハンド/腕トラッキングは実験機能です。安定しない場合は使わないでください

## マイク口パク

1. マイクデバイスを選ぶ
2. `マイク開始` を押す
3. 話した時にVRMの口が動くことを確認する

マイク口パクは音量ベースです。母音解析や高精度リップシンクではありません。

## カメラモード

1. カメラデバイスを選ぶ
2. `カメラ` モードを選ぶ
3. カメラ権限を許可する
4. 顔や体の動きがモデルへ反映されるか確認する

OBSで使う前に、Controllerのプレビューで動作確認してください。

## 表情プリセット

Controller上部の表情ボタンから、VRMの表情プリセットを切り替えられます。

主なボタン:

- 通常
- 喜
- 怒
- 哀
- 楽
- 驚
- なし

VRM 0.x / VRM 1.0 やモデルごとの表情設定により、存在しない表情は無視されます。

## VRMAを再生する

1. VRMを読み込む
2. VRMA欄で `.vrma` ファイルを読み込む
3. 再生ボタンを押す
4. 必要ならループを切り替える

VRMAはおまけ・デモ向け機能です。モデル差やモーション差によって見え方が変わります。

## モデルの位置を調整する

Controllerの位置調整で、OBS上の見え方を調整できます。

- X: 左右位置
- Y: 上下位置
- 拡大: モデルの大きさ
- 回転: モデル全体の向き

OBSでは顔が画面中央付近に来るようにすると、見栄えが安定します。

## 見た目を調整する

現在は明るめのキーライトを基本にしています。アニメ的な強いリムライトやアウトラインは今後の調整候補です。

提出前は、派手な演出よりOBSでチカつかず安定して見える設定を優先してください。

## トラブルシュート

### OBSにモデルが出ない

- OBSに貼ったURLがController表示のRender URLと一致しているか確認する
- `?obs=1&transparent=1` が付いているか確認する
- Web版の場合、`npm run dev` が起動したままか確認する
- Tauri版の場合、Controllerが開いているか確認する
- VRMをControllerで読み込み直す
- OBS Browser Sourceを再読み込みする

### 背景が透明にならない

- URLに `transparent=1` が付いているか確認する
- OBS側でブラウザソースの背景色やフィルタ設定を確認する
- 透明確認用にOBSの下へ色ソースを置く

### マイクが動かない

- Controllerで正しいマイクデバイスを選ぶ
- ブラウザまたはTauriのマイク権限を許可する
- macOSのシステム設定でマイク権限を確認する
- `マイク開始` を押し直す

### カメラが動かない

- Controllerで正しいカメラデバイスを選ぶ
- ブラウザまたはTauriのカメラ権限を許可する
- macOSのシステム設定でカメラ権限を確認する
- 他のアプリがカメラを占有していないか確認する

### Tauri版でportが5173ではない

`5173` が使用中の場合、Rust relayは近い空きportへ移動します。OBSにはControllerに表示されているURLを貼ってください。

### Tauri buildでDMG作成に失敗する

2026-06-06時点では、macOS `.app` 生成までは確認済みですが、DMG作成は未解決です。提出前に重い場合は、`.app` 直接確認またはWeb版手順を使ってください。

## 提出・デモ時のおすすめ構成

- Controller: Tauri版またはChromeで開く
- OBS: Browser Sourceに透明Render URLを貼る
- 入力: マイク口パク + 自動まばたき + 表情ボタン
- カメラ: 使える場合だけカメラモードを使う
- ハンド/腕トラッキング: 提出デモでは無理に使わない

1分デモでは、まず「VRMがOBS上で動く」「透明背景で合成できる」「カメラなしでも表情と口パクで使える」ことを見せるのが安定です。
