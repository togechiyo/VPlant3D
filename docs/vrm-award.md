# VRMアワード / #MadeWithVRM 調査メモ

最終確認日: 2026-05-20

## 概要

VRMコンソーシアムは、VRMを活用した優秀なプロジェクト・作品を称える新アワードとして「VRMアワード」を2026年より開始した。

あわせて、VRM活用プロジェクト共有サイト「#MadeWithVRM」が公開されている。VRMを活用した作品やプロジェクトを特設サイトへ登録する、またはSNSで `#MadeWithVRM` を付けて紹介することで、VRMアワードの選考対象になりやすくなる。

## VRMアワードとは

VRMアワードは、VRMアワード実行委員会が選定する、VRMを活用した優秀なプロジェクト・作品に与えられる賞である。

- 開始年: 2026年
- 発表予定: 2026年12月
- 表彰部門: 4部門
- 賞金: 総額50万円
- 参加方法: #MadeWithVRMへの登録、またはSNSで `#MadeWithVRM` を付けた投稿

従来の「アバターアワード」は、アバター文化の普及と発展、クリエイターの社会的認知度向上を目的に2020年から開催されてきた。2026年度からは視点をさらに広げ、VRMを活用したツール、ゲーム、AI Tuber、映像作品、インタラクティブ体験なども含む形で「VRMアワード」としてリニューアルされた。

## 表彰部門

VRMアワードでは、アバターを取り巻く多様な創作・開発活動を奨励するため、以下の4部門が設けられている。

| 部門 | 対象・評価基準 |
| --- | --- |
| イノベーション部門 | VRMを活用した、これまでにない革新的かつ独創的なプロジェクトや作品 |
| ツール部門 | VRMを用いた各領域のクリエイターの表現・創作・配信活動を支援する開発ツールやサービス |
| 映像部門 | VRMを活用したカメラワーク、演出、ストーリーテリングなど、3Dアバター表現の可能性を広げる映像作品 |
| エクスペリエンス部門 | VTuber、バーチャルライブ、VRゲーム、インタラクティブアートなど、VRMを活用して人々を魅了する新しい体験 |

このリポジトリで作るOBS向けアプリは、主に「ツール部門」と「エクスペリエンス部門」を狙える。

## #MadeWithVRMとは

`#MadeWithVRM` は、VRMを活用したクリエイターの作品やプロジェクトのURLを共有するための特設サイトおよびハッシュタグである。

対象例として、公式サイトでは以下が挙げられている。

- VRMの制作や配信を支援するツール
- VRMを読み込んで遊べるゲーム
- VRMを使った3D映像作品
- アバターツール
- AI Tuber関連
- アニメーション

テーマは自由で、過去作の登録も可能とされている。

## 第1回オンラインハッカソン

`#MadeWithVRM` では、第1回オンラインハッカソンも開催されている。

- 開催期間: 2026年5月20日（水）から 2026年6月7日（日）
- テーマ: VRMの活用を支援する、またはVRMを活用した作品であれば自由
- 参加特典: 会期中の参加者の中から抽選でAmazonギフトなどの贈呈予定

## 応募規約

公式サイトで確認できる応募規約は以下。

- 第三者の権利を侵害していないこと
- 投稿された作品は、VRMコンソーシアムが宣伝目的等で使用する場合がある
- 公序良俗に反する内容の投稿は禁止

VRMモデルを扱う場合は、モデルのライセンス、作者表記、再配布可否、商用利用可否、第三者利用可否を必ず確認する。

## 推奨される発表方法

公式サイトでは、プロジェクトや作品の発表にあわせて、noteやGitHubなどで開発の補足記事・メイキング記事を公開することが強く推奨されている。

審査時に伝えるべき内容は以下。

- VRMをどのように活用しているか
- 作品・プロジェクトの新規性
- 実装や演出上のこだわり
- ユーザーにとっての価値
- 開発過程や試行錯誤

## VPlant3Dで狙う方向

このリポジトリでは、OBS向けのVRM活用アプリを作る。VRMアワードの文脈では、「配信活動を支援するツール」でありながら、「VRMを活用した新しい体験」として見せるのがよい。

現時点の有力な方向は、VRMアバターと3D植物を組み合わせたOBS Browser Source向けアプリである。

たとえば以下のような体験を目指す。

- 配信画面上にVRMアバターと3D植物を表示する
- コメント、音声、リアクション、手動操作などで植物が成長する
- 植物の状態に応じてアバターが表情・視線・ポーズで反応する
- 配信者が自分のVRMモデルを読み込んで使える
- 透明背景でOBSに重ねられる
- デモでは、数分で「配信と一緒に育つ相棒」が伝わる

この方向なら、ツール部門では「配信活動を支援するOBSツール」として、エクスペリエンス部門では「視聴者参加型のVRM体験」として説明できる。

## 実装で優先したい要件

ハッカソン期間が2026年5月20日から6月7日までと短いため、まずはデモとして強い最小構成を作る。

- Webアプリとして動作する
- OBS Browser Sourceで使える
- 透明背景に対応する
- VRMモデルを読み込める
- 3D植物または植物的なオブジェクトが表示される
- クリック、キー入力、または簡易イベントで成長・反応が起きる
- アバターの表情・視線・ポーズのうち最低1つが変化する
- GitHub READMEまたはdocsに使い方とコンセプトをまとめる
- `#MadeWithVRM` に投稿しやすいスクリーンショットまたは短い動画を用意する

## 提出・発表時のメッセージ

発表時は、以下のように説明するとVRMアワードの評価軸に乗せやすい。

> VPlant3Dは、OBS上でVRMアバターと一緒に育つ3D植物オーバーレイです。配信中のコメントやリアクションが植物の成長に変わり、アバターがその変化に表情や仕草で反応します。VRMアバターを単に表示するだけでなく、配信者と視聴者の関係を「育つ日常」として可視化することを目指しています。
